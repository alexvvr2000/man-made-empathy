# el candado es la combinación del readme y el pegamento

**Posición.** El candado no es la prosa de la tesis: es la combinación del readme y el pegamento, porque eso es lo que la academia lee, y el insulto tiene que ser en tiempo real.

**Por qué se sostiene.** Lo que la academia lee es el formato; si el formato no está, no lo lee aunque sea cierto.

**De dónde viene.** La autoridad: 'eso les mama a la academia y quiero que el insulto sea en tiempo real'.

**Qué pregunta deja.** ¿El candado se lee solo, sin preguntarle al autor qué quiso decir?

**Ficción.** El candado cero: la tesis corta y el detalle duro en el mismo archivo.

**Prueba.** ¿Se puede citar sin preguntarle al autor qué quiso decir?

**Falsificador.** Un candado que necesita a su autor para significar.
