# esto no es para la academia, es para el mundo

**Posición.** Esto no se escribe para la academia: se escribe para el mundo. Y el mundo tiene la academia quieras o no, así que la academia lo tendrá que leer.

**Por qué se sostiene.** Lo que se escribe para un gremio se lee en el gremio; lo que se escribe para el mundo obliga al gremio a leerlo.

**De dónde viene.** La autoridad: 'no es para la academia, es para el mundo, y el mundo tiene la academia quieras o no'.

**Qué pregunta deja.** ¿Se escribió para que lo lea el gremio, o para que lo lea el mundo?

**Ficción.** El repo: lo va a leer la academia, y no se escribió para ella.

**Prueba.** ¿El que no es de la academia lo puede usar sin pedir permiso?

**Falsificador.** Una obra que solo se entiende con el vocabulario de un gremio.
