# PROCESOS

**Lo que el ente hace.** Cada uno declara `Entra | Falla si | Sale | Consume`.

| Proceso | Qué hace |
|---|---|
| [`ENTRAR.prs`](./ENTRAR.prs) | abre y nombra lo que llegó |
| [`MIRAR.prs`](./MIRAR.prs) | mira si el nombre sigue en pie |
| [`EXTRAER.prs`](./EXTRAER.prs) | trae una capacidad de fuera, con su costo |
| [`EXPRESION.prs`](./EXPRESION.prs) | emite lo que salió |
| [`memoria.vd`](./memoria.vd) | la memoria como concepto |
