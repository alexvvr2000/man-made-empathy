# EL ENTE — esto es lo que se copia

**Copia esta carpeta a tu proyecto, renómbrala, y llena tres corchetes.**

```
1. COPIAR   esta carpeta, a la raiz de tu proyecto.
2. PUERTA   ENTRAR.md -> AGENTS.md en la raiz.
3. LLENAR   el ente.vd: nombre, falta, y quien contesta.
4. CORRER   una tarea de verdad.
```
