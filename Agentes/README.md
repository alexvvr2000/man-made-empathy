# Agentes con alma de script

Me encanta cómo ahora ya hay forma de hacer miles de cosas con esta tecnología.

Pero igual necesitamos un esqueleto para sostenernos, así tenemos apoyo hacia donde sea que necesitemos ir.

Así que aquí no estoy creando un agente autónomo que pueda hacer lo que quiera, sino uno que sabe que está cumpliendo un propósito que el usuario que lo empezó le dio, un propósito que tiene que cumplir, incluso si llegar a él significa hacer que su propio creador cambie de parecer.

Así no caemos en el error de creer que no sabemos lo que hacemos.
