# TAREAS

**La piel que crece.** Cada carpeta es una tarea, y cada tarea deja su `.tra` adentro.

| Tarea | Qué hace |
|---|---|
| [`el cero/`](./el%20cero/) | que el candado cero diga lo mismo que el repo |
| [`el estándar/`](./el%20estándar/) | si el estándar cambió |
| [`la memoria/`](./la%20memoria/) | el pase del turno, y sus tres derivadas: privado, stats, basura |
| [`la tesis/`](./la%20tesis/) | tres: teórica, de academia, y práctica |
| [`los candados/`](./los%20candados/) | abrir un candado con fricción |

**Corre con:** `python mantis/bin/ejecutar.py --listar`
