# BIN

**Lo que este mundo ya tiene para cumplir los cortes.** No es el estándar: es lo concreto.

| Script | Qué corre |
|---|---|
| `ejecutar.py` | la única entrada: corre una tarea, o verifica todas |
| `cero.py` | que el candado cero diga lo mismo que el repo |
| `estandar.py` | si el estándar cambió desde la última corrida |
| `integridad.py` | si el 1 sigue siendo el 1 |
| `tareas.py` | la piel que se rehace cuando entra o sale una tarea |
| `privado.py` | la memoria reducida a lo que se puede publicar |
| `stats.py` | la sesión, contada desde su registro |
| `basura.py` | lo que git guarda y el repo ya no tiene |
| `pruebas.py` | si las pruebas del autor se pueden correr |
| `piso.py` | si este mundo puede lo que declara |

**Un mundo que no tenga Python pone lo suyo aquí, y lo declara en su `RUTA.pr`.**
