# FUENTES — de dónde viene cada nombre, y qué se toma de la obra

**Qué es.** **El registro de los nombres del repositorio, y de las obras ajenas que se citan, con qué se toma de cada una.**
**Y lo que NO es:** **no es una bibliografía.** **Con una IA al alcance, tener fuentes ya no es la parte difícil: la parte difícil es decir cómo se usaron, y desde dónde se miró. Eso es [`./estandar/salida/CONTEXTO.md`](./estandar/salida/CONTEXTO.md), y aquí se remite.**

**Sesgo:** se lee desde el que puede reclamar un nombre, no desde el que lo eligió.
**Límite:** no es asesoría legal. **Dice de dónde viene, y qué se toma; no certifica quién llegó primero.**
**Firma:** humano:autoridad · máquina:quien lo lea.
**Estado:** vigente.

## La regla

**El nombre de una obra se cita una vez, con su autoría, y no se usa como nombre propio del sistema.** **Cuando un nombre del repositorio coincide con el de una obra, se declara abajo, con lo que se toma y lo que no.**

## 4. Los límites de uso

1. El nombre de una obra no se usa como nombre propio de un sistema, un ente o un estándar.
2. En cada pieza que cite una obra, va su referencia completa, y la obra pertenece a sus autores: no se reproduce.
3. No se usan imágenes, logos, diseños ni frases largas de ninguna obra. Solo el nombre y la idea, y solo para referirse a ella.
4. Cuando haya duda, se cambia por una palabra en español que diga el mismo acto.
5. Citar para analizar es legítimo y no pide permiso. Usar el nombre como propio, sí lo pide.
