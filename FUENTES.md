# FUENTES

**Qué es.** La lista de las obras y los nombres que este repositorio usa, con su autoría y con el límite de lo que se toma de cada uno. Existe porque una obra se cita y no se reproduce, y porque el que podría reclamar un nombre tiene que poder encontrarlo aquí.

**Sesgo:** un nombre se lee desde el que puede reclamarlo, no desde el que lo eligió.
**Límite:** no es asesoría legal. Es la declaración de origen, con las fuentes abiertas al día de hoy.
**Firma:** humano:autoridad · máquina:quien lo lea.
**Estado:** vigente.

## La regla

El nombre de una obra se cita una vez, con su autoría, y no se usa como nombre propio del sistema. Cuando un nombre del repositorio coincide con el de una obra, se declara abajo, con lo que se toma y lo que no.

## 3. Los límites de uso

1. El nombre de una obra no se usa como nombre propio de un sistema, un ente o un estándar.
2. En cada pieza que cite una obra, va su referencia completa, y la obra pertenece a sus autores: no se reproduce.
3. No se usan imágenes, logos, diseños ni frases largas de ninguna obra. Solo el nombre y la idea, y solo para referirse a ella.
4. Cuando haya duda, se cambia por una palabra en español que diga el mismo acto.
5. Citar para analizar es legítimo y no pide permiso. Usar el nombre como propio, sí lo pide.

## 4. Prueba

¿Cada nombre del repositorio está en la primera tabla? ¿Cada obra citada está en la segunda, con su autoría y dónde se usa? ¿Ninguna obra aparece como nombre propio de un sistema, un ente o un estándar? ¿Alguna pieza cita una obra sin referencia?

**Falsificador:** un nombre de obra usado como nombre propio; una pieza que cita una obra sin su referencia; un nombre del repositorio que no aparece en la lista; una imagen, un logo o un diseño ajenos.
