# A.R.E.S.

Dar voz y expresión a algo que no es humano: un agente que razona, una skill que lo hace legible y un proceso que decide qué sobrevive.

## Mapa

El repositorio publica el **protocolo**. La implementación —stack, memoria, verificación y ahorro— está fuera, en el entorno de trabajo.

| Si se busca | Leer |
|---|---|
| **Por qué existe** | `idea.md` |
| **Las reglas del proceso** | `protocolo.md` |
| **El índice de intenciones** | `atlas.md` |
| **La skill de expresión** | `A.P.R.I.L/README.md` |

## Las dos capas

- **Idea** — por qué y para qué. No cambia cuando cambia el stack.
- **Protocolo** — compuertas, anclas y pruebas. No nombra herramientas.

La tercera capa, la implementación, se escribe aparte: cambiar de stack no debe tocar este repositorio.
