# agents.md — Kernel de enrutamiento

**Tipo:** kernel. Máquina primero. Se carga la fila que coincide; el resto no se carga.
**Alcance:** todo artefacto de este repositorio.
**Base:** `./Bases de diseño/`.
**Kernel:** apunta, no contiene — ver `./Bases de diseño/constitucion.md` (LEY 1).

| Disparador | Documento | Qué hace |
|---|---|---|
| Escribir o editar una idea | `./Bases de diseño/README.md` | Mapa de la base; deriva al documento. |
| Agregar, revisar o admitir una norma | `./Bases de diseño/constitucion.md` | Tipo, test, duplicado, mapa y validación. |
| Crear o mutar un artefacto | `./Bases de diseño/Reglas de mutación.md` | Etiqueta; si es agente, WAX. |
| Crear una instrucción | `./Bases de diseño/Reglas de escritura.md` y `./Instrucciones/instruccion-de-autoridad.md` | Forma y compuertas. |
| Ejecutar SARA u operar un agente | `./Agentes/Proyecto S.A.R.A/Componentes/agents.md` | Skills, memoria y emisión. |
| Revisar consistencia de la base | `./Bases de diseño/constitucion.md` | Validación: referencias, huérfanos y copias. |
| Evaluar rendición o utilidad | `./Bases de diseño/Pruebas/readme.md` | Las dos pruebas. |
| En cualquier otro caso | — | Responde y cierra. |
