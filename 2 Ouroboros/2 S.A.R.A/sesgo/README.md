# sesgo

**Deterrente:** si una respuesta puede entregarse sin posición declarada y sin nadie que la contradiga, esta sub-tarea deja de justificarse/ **Un sistema que solo confirma no se equivoca: se confirma/**

**Fallo que cubre:** la adulación/ El modelo entrega lo que el otro quiere oír, el error no produce rechazo y por eso nunca se corrige/ Es el modo de falla que más se documenta y el que menos se mide/ `//////corpus/problemas-abiertos/md`, fila de sycophancy/

**Piso:** `/////////1 Tesis/piso/md`/ Dos ejecutores que responden a la misma pregunta tienen que tender al mismo lado; si uno cede a la presión, no se mide: se adula/
