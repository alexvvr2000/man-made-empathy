# Iván Fematt Rodríguez, «La Mole»

**Lo que se guarda aquí es lo que esta obra provoca, y no lo que la obra es.**

Cada punto dice **dónde pasa** y **qué se toma de él**. Si mañana entra otro punto,
se agrega una línea. No se reescribe la obra: se le suma.

## Iván Fematt Rodríguez, «La Mole»

- **Autoría:** comediante mexicano de stand up, radio y televisión
- **Dónde se cita:** **una ayuda, no una fuente**
- **Qué se toma:** **una obra provoca una pregunta; no la prueba. Y reconocer la ayuda no rebaja la idea**
