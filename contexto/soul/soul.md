# Soul

**Lo que se guarda aquí es lo que esta obra provoca, y no lo que la obra es.**

Cada punto dice **dónde pasa** y **qué se toma de él**. Si mañana entra otro punto,
se agrega una línea. No se reescribe la obra: se le suma.

## Soul

- **Autoría:** Pete Docter, Kemp Powers y Dana Murray; Pixar, 2020
- **Dónde se cita:** la vida no se acaba en un punto: se vive para coexistir, no para matarse unos a otros
- **Qué se toma:** **una vida con un propósito no es la única vida que vale: la que se vive a diario también**
