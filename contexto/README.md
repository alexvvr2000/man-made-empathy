# CONTEXTO

**Aquí va lo que cada obra provocó, y cómo se usó. Es del autor, y no lleva formato.**

**`FUENTES.md` dice quién la hizo y cuándo, en APA 7.** **Esto dice por qué está aquí.**

| | |
|---|---|
| **`FUENTES.md`** | **el registro: autoría, año, obra. Formato estándar, y se puede citar** |
| **`contexto/`** | **el porqué: qué provocó, y en qué pieza del repo se usa** |

## Lo que hay

**Una carpeta por obra, y adentro sus puntos.** **Agregar un ejemplo es una línea nueva; no se reescribe la obra.**

```
contexto/
├── watchmen/                 watchmen.md      (cómic, película, serie: tres puntos, y se perdían)
├── adventure-time/           …               (Marceline, y Jake)
├── dragon-ball/                              (Videl)
├── avatar-the-last-airbender/                (el tío Iroh y Lu Ten)
└── … 59 en total
```

## Y por qué esto no tiene el formato de FUENTES.md

**Porque el formato le sirve al que va a citar.** **Esto no se cita: se lee.** **Y si mañana cambia de forma, cambia: lo que se sostiene es lo que dice.**

**Y por eso el repo lo demuestra:** **el registro tiene formato porque hay que tenerlo; el contexto no, porque no hace falta.**
