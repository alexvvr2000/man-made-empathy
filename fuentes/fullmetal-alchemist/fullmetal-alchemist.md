# Fullmetal Alchemist

**Lo que se guarda aquí es lo que esta obra provoca, y no lo que la obra es.**

Cada punto dice **dónde pasa** y **qué se toma de él**. Si mañana entra otro punto,
se agrega una línea. No se reescribe la obra: se le suma.

## el círculo de transmutación de todo el país

- **Autoría:** Hiromu Arakawa; Square Enix, desde 2001
- **Dónde se cita:** la semilla: se planta sin saber qué, y escala a algo que no sabes de dónde salió
- **Qué se toma:** **el plan que se construye años antes, con piezas que nadie sabía que eran una sola cosa**
