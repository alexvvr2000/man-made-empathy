# Sócrates

**Lo que se guarda aquí es lo que esta obra provoca, y no lo que la obra es.**

Cada punto dice **dónde pasa** y **qué se toma de él**. Si mañana entra otro punto,
se agrega una línea. No se reescribe la obra: se le suma.

## Sócrates, y su mayéutica según Platón, Teeteto y El banquete

- **Autoría:** dominio público; el Sócrates histórico no escribió nada, y lo que se cita es el de Platón
- **Dónde se cita:** la pregunta que hace parir la idea
- **Qué se toma:** **la mayéutica: extraer por pregunta, y el que contesta se queda con la respuesta**
