# Undertale

**Lo que se guarda aquí es lo que esta obra provoca, y no lo que la obra es.**

Cada punto dice **dónde pasa** y **qué se toma de él**. Si mañana entra otro punto,
se agrega una línea. No se reescribe la obra: se le suma.

## Undertale, y su comunidad

- **Autoría:** Toby Fox, 2015
- **Dónde se cita:** las revoluciones: algo pequeño que escala sin que se sepa de dónde salió
- **Qué se toma:** **una obra hecha por una persona, y una comunidad que la hizo crecer sola**
