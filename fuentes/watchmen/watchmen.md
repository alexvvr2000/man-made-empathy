# Watchmen

**Lo que se guarda aquí es lo que esta obra provoca, y no lo que la obra es.**

Cada punto dice **dónde pasa** y **qué se toma de él**. Si mañana entra otro punto,
se agrega una línea. No se reescribe la obra: se le suma.

## Watchmen, el cómic

- **Autoría:** Alan Moore y Dave Gibbons; DC Comics, 1986-1987
- **Dónde se cita:** lo que se dice y lo que se deja ver
- **Qué se toma:** **el cómic incluye un cómic de piratas dentro, para decir su punto de otra manera, y no era el punto: era la pregunta**

## Watchmen, la película

- **Autoría:** Zack Snyder; Warner Bros., 2009
- **Dónde se cita:** lo que se dice y lo que se deja ver
- **Qué se toma:** **le saca lo que se puede digerir fácil, y el mensaje se pierde en el camino**

## Watchmen, la serie

- **Autoría:** Damon Lindelof; HBO, 2019
- **Dónde se cita:** lo que se dice y lo que se deja ver
- **Qué se toma:** **el autor esperaba la serie sobre el pulpo final de la película, y no era eso: ahí vio que había algo grande**
