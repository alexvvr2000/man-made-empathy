# FUENTES

**Una carpeta por obra. Adentro, sus puntos.**

```
fuentes/
├── watchmen/            watchmen.md          (3 puntos: cómic, película, serie)
├── adventure-time/      adventure-time.md    (2 puntos: Marceline, Jake)
├── avengers-infinity-war/                    (2 puntos)
├── dragon-ball/                              (1 punto)
└── … 59 en total
```

## Qué es un punto

**No es lo que la obra es: es lo que la obra provoca.**

**Cada punto dice tres cosas:**

| | |
|---|---|
| **Autoría** | **de quién es, y de cuándo** |
| **Dónde se cita** | **en qué pieza del repo se usa** |
| **Qué se toma** | **qué provoca, exactamente** |

## Por qué está partido y no en una tabla

**Porque una tabla obliga a buscar la fila de la obra y reescribirla.** **Y así se perdió un ejemplo de Iron Man: la frase de 2008 quedó sobrescrita por la de 2018.**

**Aquí, agregar un punto es agregar un `## `. No se toca lo que ya estaba.**

## Lo que no enlaza, y se dice

**`_la tabla.md` es la copia literal, y sus enlaces son los de su era.** **Y las históricas, igual: apuntan a rutas de cuando se escribieron.**

**No se arreglan: son la prueba de lo que había.** **Un archivo histórico que se actualiza deja de decir lo que decía.**

## La tabla original

**[`_la tabla.md`](./_la%20tabla.md) es `FUENTES.md` entero, como estaba.** **No es una copia de respaldo: es la prueba de que nada se perdió en la partición, y se queda hasta que el autor diga que se va.**

## Y una cosa que todavía no está

**Las tesis citan en prosa, y no enlazan a estas carpetas.** **Cada «de dónde viene» de una tesis debería apuntar a su obra aquí.** **Eso es lo que sigue, y no se hace solo: se hace con la autoridad delante.**
