# GLOSARIO — el nombre vigente de cada cosa, y dónde vive

**Qué es.** La lista de los términos que este repositorio usa, con el nombre que rige hoy y el sitio donde está su definición. **Existe porque un lector nuevo —sobre todo un revisor— necesita una página, y porque el repositorio cambió de nombre a mitad de camino y eso se queda escrito.**

**Sesgo:** el término se lee desde el que llega sin haber visto el repo, no desde el que lo escribió.
**Límite:** **no define: enruta.** **Una definición copiada se desincroniza en la siguiente mutación.**
**Firma:** humano:autoridad · máquina:quien lo lea.
**Estado:** vigente.

## La regla

> **Un término, un nombre vigente. Los anteriores quedan con `Reemplaza:`, visibles, y no se usan como si existieran.**

**Y la prueba de que esto sirve:** **si un término aparece dos veces con dos nombres, alguno de los dos está de más.**

## 3. Las tres cosas que la gente confunde

| Término | Qué es | Qué NO es |
|---|---|---|
| **candado** | **una idea que se puede abrir con fricción, y que deja lo que aguantó** | **no es una tesis: es el contexto que la sostiene** |
| **candado cero** | **la tesis. Hay uno, y se sostiene solo** | **no es el primero de una lista: es la pregunta que se contesta** |
| **contexto refutable** | **los otros candados: se pueden tumbar sin que la tesis caiga** | **no es la tesis, y no se manda como si lo fuera** |
| **llave** | **todo lo que permite abrir: el estándar, el ente, la fricción** | **no es la tesis: sin llave, la tesis no se abre** |

## 5. Las palabras de todos los días, que también se unifican

| Se dice | Y no |
|---|---|
| **el ente** — cuando es un alma, o un ente del estándar | *la entidad*, *el sistema* |
| **la pieza** — cuando es una parte de un ente | *el módulo*, *el componente* |
| **la tarea** — una carpeta con su `.tra` y sus `.prs` | *el folder* cuando es una tarea |
| **el mundo** — lo que un `RUTA.pr` declara | *el entorno*, *la plataforma* |
| **la era** — lo que caduca: el lenguaje, la herramienta, la versión | *la época* |
| **el criterio** — lo que sostiene una decisión, y no la máquina que la corre | *la inteligencia*, *el modelo* |

## Prueba

**¿Cada término vive con un solo nombre? ¿Cada nombre muerto tiene su reemplazo? ¿Un término de este glosario se usa como si existiera? ¿El glosario enruta en vez de definir?**

**Falsificador:** un nombre muerto usado como vivo; dos nombres para la misma cosa; un término sin dónde vivir; una definición copiada aquí en vez de citada.
