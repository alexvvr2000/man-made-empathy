# FUTURO es el nombre del lenguaje de procesos

**Posición.** FUTURO no es solo la carpeta: es el nombre del nuevo lenguaje de procesos del repo. La carpeta futuro/ es donde el lenguaje vive, y el estandar del lenguaje se llama futuro.

**Por qué se sostiene.** Cuando el lugar tiene nombre propio, deja de ser un cajon y pasa a ser el lenguaje. Y el nombre se pone antes que la version final porque el lenguaje ya se usa: se corrige en el siguiente.

**De dónde viene.** La autoridad, y el repo.

**Qué pregunta deja.** ¿Como se llama el lenguaje cuando su carpeta es su nombre?

**Ficción.** Ninguna: es el nombre del lenguaje.
