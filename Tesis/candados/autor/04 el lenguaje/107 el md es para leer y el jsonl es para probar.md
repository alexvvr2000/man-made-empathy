# el md es para leer y el jsonl es para probar

**Posición.** Un chat con tool calls no se pierde en md si se separa: el md lleva la conversacion y las llamadas legibles, y el jsonl lleva el evento crudo con su uso. Lo que no se puede es meter el crudo en el md ni el md en el crudo.

**Por qué se sostiene.** Y la cuenta lo dice: esta sesion tiene 1004 tool call y 1024 tool result contra 305 mensajes del autor. O sea, la parte mas interesante es la que no es conversacion, y si se aplana a prosa se pierde justo lo que sirve de prueba. Por eso el md es la lectura y el jsonl es la prueba.

**De dónde viene.** La sesion medida hoy.

**Qué pregunta deja.** ¿Si el md pierde las tool calls?

**Ficción.** Ninguna: es medicion.
