# el nombre real

**Posición.** El nombre se lee de un tiron; la expansion va adentro; el nombre que solo se deletrea es etiqueta.

**Por qué se sostiene.** Un nombre sin acto es una mentira dicha con buena diccion.

**De dónde viene.** La autoridad, y el repo: los nombres que ya tenían las piezas.

**Qué pregunta deja.** ¿Como se nombra lo que no se puede describir?

**Ficción.** Ninguna: los nombres de este repo, que ya se leen de un tirón.

**Prueba.** Un nombre que dice el acto, y que se lee de un tiron.

**Falsificador.** Un nombre que solo se puede usar deletreando su acronimo.
**Origen de este falsificador:** **escrito por el agente, y no abierto con fricción todavía.** **Se lee como hipótesis, no como prueba.**

**Se abre con fricción, y no se reescribe: `../../../mantis/tareas/los candados/abrir.prs`.**
