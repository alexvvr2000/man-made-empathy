# IMA.md — el índice del ejemplo: qué folder corre qué proceso

**Nombre.** RUTA — **R**econocimiento, **U**bicación, **T**razo, **A**cción. La expansión dice el acto: decir qué folder corre qué proceso, y marcarse gastado cuando la forma deja de servir.

**Unidad:** índice.
**Aplica a:** enrutar.
**Tipo:** se intercambia. No es estándar: es el índice que se gasta.
**Lector:** el alma, que no sabe qué va a encontrar.
**Dueño:** humano:autoridad.
**Estado:** vigente.

**Sesgo:** el folder se enruta por su intención, no por su nombre.
**Límite:** no decide si el proceso sirve: dice cuál corre.
**Firma:** humano:autoridad · máquina:quien enrute.

## Las filas

| Folder | Qué se hace ahí | Proceso | Deja |
|---|---|---|---|
| **`lo que llega`** | **recibir y nombrar** | `ENTRAR.prs` | `lo que llega.tra` |
| **`el nombre`** | **mirar si el nombre sigue en pie** | `MIRAR.prs` | `el nombre.tra` |
| **`el dato que falta`** | **decir qué no hay, y qué lo cierra** | `EXTRAER.prs` | `el dato que falta.tra` |

**Tres folders, tres procesos, tres `.tra`.** **Y ni uno menos: un folder sin `.tra` es un paso que no pasó.**

## Lo que este índice no hace

**No guarda el rastro del alma:** lo guarda cada `.tra`.
**No decide qué folder sigue:** lo dice el alma, y este índice lo enruta.

## La gastadura

```
RUTA:        el índice por intención
Gastado si:  llega un folder que ninguna fila cubre, y se corre igual
Se cambia:   el índice, y no el alma
```

## Prueba

¿Cada folder tiene su fila? ¿Cada fila dice qué proceso y qué deja? ¿Se declara cuándo se gasta?

**Falsificador:** un folder sin fila; una fila sin proceso; una fila sin lo que deja; un índice que se presenta como estándar.
