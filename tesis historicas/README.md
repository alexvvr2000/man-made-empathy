# TESIS HISTÓRICAS

**Aquí no hay nada, y es a propósito.**

**Estas son las tesis que me llevaron hasta aquí: S.A.R.A, los principios, la segunda corrida, las eras que ya no están.** **Están en git, completas, y no se cargan al repo hasta que alguien las pida.**

**Por qué vacía:** **más de mil archivos de una era muerta no le sirven a quien abre esto hoy.** **Lo que sirve es saber que existieron, y poder verlos si hacen falta.**

## Cómo se ven

```powershell
python mantis/bin/ejecutar.py historicas
```

**Eso lista las eras: cuántos archivos tuvo cada una, y en qué commit se fue.**

**Y para traer una, a esta carpeta:**

```powershell
python mantis/bin/ejecutar.py historicas --sacar "S.A.R.A"
```

**Se trae a esta carpeta, con su fecha.** **Y se lee.** **Y cuando ya no haga falta, se borra: git la sigue teniendo.**

## Lo que esta carpeta no es

**No es un archivo de descartes: es la genealogía.** **Los 93 candados de hoy salieron de aquí.**

**No se cita como vigente.** **Se cita como lo que fue, con su fecha.**

**Y no es obligatorio leerla para entender el repo.** **El repo se entiende sin esto; esto se lee cuando se quiere saber de dónde vino.**
