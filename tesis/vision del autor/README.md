**No está, y se dice.** **Va al final, y cuando cierre, entra aquí como una carpeta con sus dos archivos.**

## Y por qué solo dos

**Porque una teoría que se lee como nueve piezas sueltas no se lee como teoría.** **El documento las ordena; las piezas son el material. Y el material vive dentro, no al lado.**
