# ATLAS — derrotero del paso 3

**Tipo:** disparador. Solo las filas que coinciden se cargan; el resto no.
**Carta:** [`./rastro.md`](./rastro.md). Sin carta no se lee.
**Deterrente:** [`./carga.md`](./carga.md). Sin él, no se sabe qué se pierde si ATLAS promete verdad.
**Piso:** `../../1 Tesis/piso.md`.
**Abstracción:** `../` — ATLAS es el paso 3 de `2 Ouroboros/`.

## Entra | Falla | Sale | Consume

**Variables:** mensaje · techo · sesgo · canal · quién recibe
**Peor:** se emite sin techo declarado y el otro entiende algo distinto de lo que se quiso, sin forma de saberlo.
**Quién:** quien emite, y quien recibe.

- **Entra:** lo que se quiere expresar y a quién.
- **Falla si:** no hay fila para lo que se va a expresar; se emite sin techo; se busca por nombre de método.
- **Sale:** la forma que se carga, o [VACÍO - SIN FORMA].
- **Consume:** quien emite la forma.

**Prueba:** ¿cada fila tiene su forma y su consecuencia? ¿el vacío se declara?

**Falsificador:** una emisión sin fila; una búsqueda por nombre de método.

## La tabla: si se va a...

| Si se va a... | Se carga | Si no... |
|---|---|---|
| emitir algo para que el otro lo entienda o actúe | `./Proceso ATLAS.md` | se emite sin techo declarado |
| fijar qué debe entender el otro lado, y cómo se comprueba | `./Proceso ATLAS.md`, `Techo` | el mensaje llega y nadie sabe si entendió |
| declarar desde dónde se emite y qué no se ve | `./Proceso ATLAS.md`, `Sesgo declarado` | se emite como si el emisor no tuviera posición |
| decidir informar, preguntar, ordenar, advertir o persuadir | `./Proceso ATLAS.md`, `Modo del mensaje` | el mensaje hace dos cosas a la vez |
| comprobar que el otro puede reconstruir sin el emisor | `./Proceso ATLAS.md`, `Pruebas` | se mide porque obedeció, no porque pudo |
| buscar una forma por intención | `./indice de formas.md` | se busca por nombre de método |
| registrar una forma nueva o un fallo de emisión | `./indice de formas.md` | la forma se pierde y se reinventa |
| saber si una forma pasó su sello | `./indice de formas.md`, `Franjas` | una hipótesis se presenta como regla |

**Una fila, un proceso.** Si se cargan dos, se declara por qué: **dos puertas abiertas a la vez es la forma en que se pierde el rastro de por qué se hizo algo.**

## Vacío

**Lo que no entra en una fila se declara `[VACÍO - SIN FORMA]` y se pregunta; no se improvisa.**

## Transiciones

- No hay fila para lo que se va a expresar → `[VACÍO - SIN FORMA]`.
- El techo no se alcanzó → se registra el fallo en `./indice de formas.md`.
- La idea no se puede expresar → `../1 Guantelete — primitivo/primitivos/claridad.md`.
- En cualquier otro caso → se enruta, se emite y se cierra.

## Lectura

**Sin derrotero no se emite una forma; con él, se emite la que coincide y se lee su techo.**
