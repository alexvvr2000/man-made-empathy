## Lo que el barrido enseñó, y va a `ideas/`

**1. El ejemplo y el argumento se mezclaban en el mismo párrafo.** **Ahora se separan: el ejemplo se cita, y el argumento se sostiene.**

**2. Una obra puede sostener a varios argumentos, y eso no la multiplica.** **`All-Star Superman` sirve a tres, y tiene una sola ficha.**

**3. Y el chiste de internet es un ejemplo legítimo, si se declara como chiste.** **`Jujutsu Kaisen` lo prueba.**
