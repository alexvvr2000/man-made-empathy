**Sesgo:** se lee desde el que llega sin nada instalado.
**Límite:** **lo mínimo para ver las tesis históricas, y nada más.** **Si hace falta más, se agrega cuando se pida.**

## Qué hay

| Lo que | Para qué |
|---|---|
| **`python` 3** | **`bin/ver-tesis` y `bin/estado` lo usan** |
