# EL ESTÁNDAR

**Cómo se escribe, y qué se sostiene.** **Se consulta, y no se copia.**

**Clase:** se cumple. **Estado:** vigente.

**Sesgo:** **el estándar no dice cómo se escribe: dice qué se tiene que poder contestar.**
**Límite:** **no se copia a los proyectos.** **Si cada uno tuviera su copia, cada uno tendría su versión de la regla.**
**Firma:** humano:autoridad.

## Carga

| Si pasa esto | Se pierde | Y el síntoma es |
|---|---|---|
| **el estándar nombra un lenguaje** | la vigencia | muere cuando cambia la era |
| **la fricción se quita sin firma** | la autoridad | nadie sabe quién la quitó |
| **el silencio se lee como acuerdo** | la voz | el que no podía hablar, desaparece |
| **una medida no declara su caso malo** | la medida | el promedio miente |
| **el contexto no se declara** | el origen | lo heredado se presenta como propio |

## Prueba

**¿El estándar nombra un lenguaje? ¿Cada pieza dice su límite? ¿Lo que se quita deja firma? ¿El silencio se lee como silencio?**

**Falsificador:** un estándar que nombra su lenguaje; una fricción quitada sin firma; un silencio leído como acuerdo; una medida sin su caso malo.
