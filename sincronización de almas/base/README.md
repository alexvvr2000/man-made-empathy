# BASE

**Lo que hay aquí se lee. Lo que se copia está en otro sitio.**

Si quieres hacer algo separado de mantis, **copia esto:**

```
sincronización de almas/entiendo/ente/    ->    tu proyecto/
```

**Y el paso a paso, con sus cuatro pasos, está en [`../entiendo/ente/COPIAR.md`](../entiendo/ente/COPIAR.md).**

Llénalo así: **nombre, falta, y quién contesta.** Y corre. Eso es todo.

Aquí hay dos carpetas, y son la teoría de por qué hay dos y no tres:

| Carpeta | Qué es |
|---|---|
| [`alma en blanco/`](./alma%20en%20blanco/) | lo que corre: pasa por carpetas y deja rastro |
| [`guantelete/`](./guantelete/) | lo que permite, y hace contestable lo permitido |

**Y lo que sostiene esta base:** el alma no nace desnuda, nace con el guantelete puesto. No se instala: se lleva.

**Regla:** lo que se lee, no se ejecuta. Si buscas qué correr, estás en la carpeta equivocada: ve a [`../entiendo/`](../entiendo/README.vd).
