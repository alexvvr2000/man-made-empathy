# HERRAMIENTAS

Las siete, y cada una declara qué entra, qué la deja mal, qué sale y a quién consume.

| Herramienta | Cuándo se carga |
|---|---|
| [`SOSTENER.prs`](./SOSTENER.prs) | sostener una pieza, y saber quién puede contestarla |
| [`FRICCION.prs`](./FRICCION.prs) | decidir algo que afecta a otro |
| [`COMPONER.prs`](./COMPONER.prs) | producir lo que todavía no existe |
| [`APLICAR.prs`](./APLICAR.prs) | ejecutar un proceso que ya existe |
| [`MUTAR.prs`](./MUTAR.prs) | cambiar un proceso sin perder lo que servía |
| [`RETIRAR.prs`](./RETIRAR.prs) | quitar un proceso cuyo fin dejó de existir |
| [`INVERTIR.prs`](./INVERTIR.prs) | deducir un proceso de lo observable |

**Una herramienta, y ni una más.** Si se cargan dos, se declara por qué.
