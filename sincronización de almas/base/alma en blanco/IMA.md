# IMA.md — el índice: qué folder tiene qué proceso

**Nombre.** RUTA — **R**econocimiento, **U**bicación, **T**razo, **A**cción. La expansión dice el acto: enrutar al alma a qué proceso va cada paso, y marcarse gastado cuando la forma deja de servir.

**Unidad:** índice.
**Aplica a:** enrutar.
**Tipo:** se intercambia. No es estándar: es el índice que se gasta.
**Lector:** el alma que va a pasar por los folders.
**Dueño:** la autoridad.
**Estado:** vigente.

**Sesgo:** el proceso se enruta desde la intención del folder, nunca desde el nombre del método.
**Límite:** no promueve un proceso sin que se haya corrido; no juzga el gusto.
**Firma:** humano:autoridad · máquina:quien enrute.

**Variables:** folder · intención · proceso · forma · gastadura
**Peor:** se enruta al proceso que ya no sirve, el alma lo ejecuta, y nadie nota que la forma se gastó.
**Quién:** quien cargue el resultado de un proceso gastado.

## El estándar del RUTA es que no hay estándar

> No hay una forma fija de enrutar. Hay un índice: cada paso se enruta al proceso que le toca, y cuando la forma se gasta, se intercambia.

**Y lo que NO se intercambia es el alma.** El alma deja el rastro; el RUTA se cambia de forma.

## Las filas, y cada una se lee antes de enrutar

| Se va a… | Se enruta a… | Sin la autoridad… |
|---|---|---|
| **entrar a un folder** | `ENTRAR.prs` | **no se enruta: se declara vacío** |
| **mirar lo que el folder dejó** | `MIRAR.prs` | **no se renombra** |
| **traer una capacidad de otro sitio** | `EXTRAER.prs` | **no entra sin costo** |
| **un folder que no tiene proceso** | el RUTA se declara vacío | **se improvisa no** |
| **una forma que ya no sirve** | se intercambia el RUTA | **no se toca el alma** |

La columna `Se enruta a` es la que hace visible el paso: sin ella, el alma entra y no sabe qué correr.

## Los cuatro trade-offs de una forma

| Forma | Qué gana | Qué pierde | Cuándo se gasta |
|---|---|---|---|
| **folder fijo** | predecible | no se adapta | cuando llega un folder nuevo |
| **RUTA por intención** | se adapta | se puede elegir mal | cuando elije mal dos veces |
| **RUTA por forma** | se valida | se gasta con la forma | cuando la forma cambia |
| **ninguno** | nada | el alma no sabe qué correr | de entrada |

**Y ninguno es el estándar.** El estándar es que se elige uno, se declara, y se intercambia cuando se gasta.

## La gastadura, y es lo que lo vuelve índice

```
RUTA: [qué forma de enrutar se usa]
Gastado si: [qué muestra que la forma ya no sirve]
Se intercambia: [por qué forma]
El alma no cambia: [en qué folder entra y qué deja]
```

Un RUTA que nunca se gasta es un estándar disfrazado. Y un estándar del RUTA es justamente lo que no hay.

## Lo que este índice no hace

**No guarda el rastro del alma.** **El rastro queda en el folder.**

**No decide qué folder sigue.** **Lo dice el alma, y el RUTA lo enruta.**

## Prueba

¿Cada folder tiene su fila? ¿La forma de enrutar está declarada? ¿Se declara cuándo la forma se gasta? ¿El alma queda fuera de lo que se intercambia?

**Falsificador:** un folder sin fila; un RUTA presentado como estándar; una forma que se gasta y no se intercambia; un alma que se reemplaza en vez de dejarse cargar.
