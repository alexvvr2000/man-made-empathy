## Los cuatro de relación, y no se confunden

| | Qué dice | Su límite |
|---|---|---|
| **`RESONANCIA`** | **dos o más se afinan, y quién lo decide** | **no decide si vale la pena resonar** |
| **`COLMENA`** | **la resonancia entre muchos, y el acuerdo que la vuelve trazable** | **no es un enjambre: un enjambre no tiene acuerdo** |
| **`TALENTO`** | **lo que aguanta, y no lo que promete** | **no juzga si el colaborador es bueno** |
| **`EQUILIBRIO`** | **cuánto pesa cada acto, y desde dónde se piensa** | **no decide si el acto se permite: eso es `GUANTELETE`** |

**Y cada uno dice su límite, porque el que no lo dice se confunde con el de al lado.**
